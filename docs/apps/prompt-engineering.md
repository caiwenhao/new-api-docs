# 💡 提示词工程最佳实践

提示词工程是与 AI 模型有效交互的艺术和科学。本指南将帮助您掌握编写高效提示词的技巧。

## 🎯 基本原则

### 1. 明确性原则
**清晰、具体、无歧义**

❌ **不好的示例：**
```
写一篇文章
```

✅ **好的示例：**
```
写一篇800字的科技文章，主题是"人工智能在医疗领域的应用"，
包含以下要点：
1. AI 诊断技术的现状
2. 具体应用案例（至少3个）
3. 面临的挑战和未来发展趋势
目标读者是对科技感兴趣的普通大众。
```

### 2. 结构化原则
**使用清晰的格式和结构**

```
任务：[明确的任务描述]
背景：[相关背景信息]
要求：
- 要求1
- 要求2
- 要求3
输出格式：[期望的输出格式]
```

### 3. 示例驱动原则
**提供具体示例来指导模型**

```
请将以下句子改写为更正式的表达：

示例：
输入：这个东西真的很棒
输出：这个产品确实表现出色

现在请改写：这个方案挺不错的
```

## 🛠️ 核心技巧

### 1. 角色设定 (Role Playing)

```
你是一位资深的产品经理，拥有10年的互联网产品经验。
请从产品经理的角度分析以下需求的可行性...
```

**常用角色模板：**
- 专业顾问：`你是一位[领域]专家，拥有[年数]年经验...`
- 创意助手：`你是一位富有创意的[职业]，擅长...`
- 分析师：`你是一位数据分析师，专门负责...`

### 2. 思维链 (Chain of Thought)

```
请一步步分析这个数学问题：

问题：一个班级有30名学生，其中60%是女生，女生中有25%戴眼镜。
请问戴眼镜的女生有多少人？

请按以下步骤思考：
1. 首先计算女生总数
2. 然后计算戴眼镜的女生人数
3. 给出最终答案
```

### 3. 分解复杂任务

```
我需要为新产品制定营销策略。请分以下几个步骤完成：

第一步：市场分析
- 目标用户群体
- 竞争对手分析
- 市场机会识别

第二步：策略制定
- 定位策略
- 差异化优势
- 营销渠道选择

第三步：执行计划
- 时间安排
- 预算分配
- 关键指标

请逐步完成每个部分。
```

```
- 维度3
输出要求：
- 关键发现
- 数据可视化建议
- 行动建议
```

## 🎨 高级技巧

### 1. 少样本学习 (Few-Shot Learning)

```
请根据以下示例，为新产品写推广文案：

示例1：
产品：智能手表
文案：时间在手腕上跳动，健康在指尖掌控。全新智能手表，让科技与生活完美融合。

示例2：
产品：无线耳机
文案：音乐无界，自由无限。超长续航无线耳机，让每一个音符都触动心灵。

现在请为以下产品写文案：
产品：智能台灯
```

### 2. 对比分析

```
请对比分析以下两个方案的优缺点：

方案A：[详细描述]
方案B：[详细描述]

对比维度：
1. 成本效益
2. 实施难度
3. 风险评估
4. 长期影响

请以表格形式呈现对比结果，并给出推荐意见。
```

### 3. 反向思考

```
假设我们要避免项目失败，请列出可能导致失败的因素：

项目背景：[项目描述]

请从以下角度分析：
1. 技术风险
2. 市场风险
3. 团队风险
4. 资源风险

然后针对每个风险提出预防措施。
```

## ⚡ 优化技巧

### 1. 迭代改进

```
第一版提示词 → 测试结果 → 分析问题 → 优化提示词 → 再次测试
```

### 2. A/B 测试

```python
# 测试不同提示词的效果
prompt_a = "请总结这篇文章的主要内容"
prompt_b = "请用3个要点总结这篇文章的核心观点"

# 比较输出质量，选择更好的版本
```

### 3. 温度参数调节

```python
# 创意任务：使用较高温度
response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "写一个创意故事"}],
    temperature=0.8
)

# 分析任务：使用较低温度
response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "分析这个数据"}],
    temperature=0.2
)
```

## 🚫 常见误区

### 1. 过于复杂
❌ 一次性给出过多指令和要求
✅ 分步骤，逐步引导

### 2. 缺乏上下文
❌ 假设模型了解背景信息
✅ 提供必要的背景和上下文

### 3. 模糊表达
❌ 使用模糊、主观的词汇
✅ 使用具体、客观的描述

### 4. 忽略输出格式
❌ 不指定期望的输出格式
✅ 明确说明输出格式要求

## 📊 效果评估

### 评估维度
1. **准确性**：输出是否符合要求
2. **相关性**：内容是否切题
3. **完整性**：是否涵盖所有要点
4. **可用性**：输出是否可直接使用

### 评估方法
```python
def evaluate_response(response, criteria):
    scores = {}
    for criterion in criteria:
        score = rate_response(response, criterion)  # 1-10分
        scores[criterion] = score
    return scores
```
