## 🎯 计费模式

### 按使用量付费
按实际使用的 tokens 数量/调用次数计费，无需预付费，用多少付多少。

### Token 计算方式
- 输入 tokens：发送给模型的文本内容
- 输出 tokens：模型返回的文本内容
- 总费用 = 输入 tokens × 输入单价 + 输出 tokens × 输出单价
