## 🎯 计费模式

### 按使用量付费
我们采用按实际使用的 tokens 数量计费，无需预付费，用多少付多少。

### Token 计算方式
- **输入 tokens**：您发送给模型的文本内容
- **输出 tokens**：模型返回的文本内容
- **总费用** = 输入 tokens × 输入单价 + 输出 tokens × 输出单价

## ❓ 常见问题

### 计费相关

**Q: 如何计算 tokens 数量？**
A: 1 个 token 大约等于 0.75 个英文单词，或 0.5 个中文字符。您可以在控制台查看详细的 token 使用统计。

**Q: 免费额度用完后会怎样？**
A: 免费额度用完后，您需要充值才能继续使用服务。我们会在额度即将用完时提前通知您。

**Q: 可以申请发票吗？**
A: 可以。企业用户可以在控制台申请增值税专用发票或普通发票。

**Q: 支持退款吗？**
A: 充值金额不支持退款，但余额永久有效。如有特殊情况，请联系客服处理。
